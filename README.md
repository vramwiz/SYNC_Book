# SYNC_Book（本演出）

本を開く、ページをめくる、表紙を閉じる動きを作る AviUtl ExEdit2 用の3Dメディアオブジェクトです。新聞を含む14種類のプリセットから選べます。表紙やページには、内蔵の模様とお手持ちの画像が使えます。

**v1.0.0** · Windows 64ビット · AviUtl ExEdit2 2.1.16 以降

## インストール・更新

1. AviUtl2 を終了します。
2. 配布 ZIP を展開し、中の `SYNC_Book` フォルダーを AviUtl2 の `Plugin` フォルダーへコピーします。標準の配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_Book` です。更新時は同じ場所に上書きします。
3. AviUtl2 を起動し、タイムラインにメディアオブジェクト「本演出」を追加します。

[SYNC_Book.zip をダウンロード](https://github.com/vramwiz/SYNC_Book/releases/download/v1.0.0/SYNC_Book.zip)

### アンインストール

AviUtl2 を終了した状態で、`Plugin` 内の `SYNC_Book` フォルダーを丸ごと削除します。

## 本を開いてページをめくる

「本の種類」でハードカバー、文庫本、古書などを選び、**設定を反映**を押します。形状や装丁、紙面の模様は、反映後に調整できます。最初に追加したときは、装飾付きのハードカバーが閉じた状態で表示されます。

「新聞」は左綴じで、表裏と中面を同じ薄い新聞紙で描画します。表面には題字と大きな縦見出し、中面には段組みの記事、裏面にはラテ欄（テレビ・ラジオ番組表）が入ります。文字は紙面の模様として描画します。

「アニメーション」で切替パターンを選び、「進行度」の始点を `0.00`、終点を `1.00` に設定して直線移動させます。

| 切替パターン | 0.00 | 1.00 |
| --- | --- | --- |
| 表紙 → ページA | 表紙が閉じた状態 | ページAの見開き |
| ページA → ページB | ページAの見開き | ページBの見開き |
| ページB → 裏表紙 | ページBの見開き | 裏表紙が閉じた状態 |

「めくり方」は、通常（1枚）、大きく湾曲、複数ページ、連続めくり、ページを探す、風めくりの6種類です。連続めくりなどでは「めくり速度」と区間の長さに応じて途中の枚数が変わります。進行度を `1.00` から `0.00` に動かすと逆再生になり、値を固定するとその姿勢を表示できます。

## 本の形と見せ方を調整する

- **本体形状**で、閉じた本の横幅、縦横比、厚さ、綴じ方向を調整します。綴じ方向は左・右・上から選べます。
- **開き残し角度**の初期値は `0°` で、「表紙 → ページA」の進行度が `1.00` になると表紙が `180°` まで開きます。たとえば `30°` にすると `150°` まで開きます。
- **描画**は AviUtl2 標準の欄を使います。位置、中心、回転、拡大率、透明度を調整できます。本の配置基準は綴じ目です。
- **カメラ制御**を本演出より上のレイヤーに追加し、本が対象になるようにします。奥の面の遮蔽や光源、視点の調整に使います。

## 表紙やページに画像を使う

表紙・裏表紙・背表紙は、それぞれ外側と内側の画像を指定できます。画像欄を空にした面は、選択した色と模様で描画されます。

ページA・ページBの画像形式は、内蔵描画、見開き、片側のみ、左右個別から選べます。見開きは画像1を左右に分けて使います。左右個別は画像1が左、画像2が右です。上綴じでは上・下の順になります。画像配置は「引き伸ばす」または「比率を維持して切り抜く」を選べます。

「ページA位置」「ページB位置」は、本の中の位置を `0～100` で設定し、綴じ目の両側にある紙束の厚さを変えます。同じ位置では、内蔵の模様を同じように再現できます。
